# Module Summary: Network Operations

## Overview

This module introduced network operations and some of the protocols, services, and security techniques that help networks communicate and remain protected.

## Key topics

### 1. Network protocols

Network protocols are sets of rules that help devices communicate. This module discussed common protocols such as:

- **TCP (Transmission Control Protocol):** Allows two devices to form a connection and stream data.
- **ARP (Address Resolution Protocol):** Helps determine the MAC address of the next router or device on the path.
- **DNS (Domain Name System):** Translates internet domain names into IP addresses.
- **HTTPS (Hypertext Transfer Protocol Secure):** Provides a secure method of communication between clients and servers.

### 2. Virtual private networks (VPNs)

A VPN is a network security service that helps keep data private when using a public network such as the internet. The module also introduced encapsulation, the process of wrapping sensitive data in other data packets to protect it.

### 3. Firewalls and network protection

Firewalls monitor traffic to or from a network. The module introduced firewall types and functions, including:

- Stateful and stateless firewalls.
- Port filtering.
- Cloud-based firewalls.

### 4. Security zones and network segmentation

Network segmentation divides a network into smaller segments. Security zones help separate and protect internal networks from external or less trusted networks. The module glossary also introduced controlled and uncontrolled zones.

### 5. Proxy servers

A proxy server forwards requests between clients and other servers. Two types covered in the glossary were:

- **Forward proxy server:** Regulates and restricts a person's access to the internet.
- **Reverse proxy server:** Regulates and restricts the internet's access to an internal server.

## Key takeaway

Network operations involve many tools, protocols, and techniques. Understanding how these work helps security analysts communicate about network activity and understand how network infrastructure is protected.
