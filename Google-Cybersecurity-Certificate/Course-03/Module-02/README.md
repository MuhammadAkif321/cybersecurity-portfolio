# Module 2: Network Operations

This module covers how devices communicate across networks and how network infrastructure can be protected.

## What I learned

- Common network protocols, including TCP, ARP, HTTPS, and DNS.
- How virtual private networks (VPNs) can help maintain privacy when using a public network.
- How firewalls, security zones, and proxy servers help secure network infrastructure.
- Why network operations involve different tools, protocols, and techniques to keep networks running smoothly and securely.
