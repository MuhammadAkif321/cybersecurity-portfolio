# Module 1: Network Architecture and the TCP/IP Model

This folder documents my learning from Module 1 of Course 3 of the Google Cybersecurity Professional Certificate.

## Module overview

This module introduced the structure of computer networks, common networking devices, cloud networks, and the TCP/IP model. It explained how the TCP/IP model helps technicians and security analysts communicate where network problems have occurred.

## Topics covered

- Local Area Networks (LANs) and Wide Area Networks (WANs)
- Common networking devices: hubs, switches, routers, and modems
- Cloud networks and their benefits
- The TCP/IP model and its role in describing network communication

## Learning takeaway

Understanding network structure and the purpose of networking devices provides a foundation for learning how data moves between devices and networks. The TCP/IP model also gives technical teams a shared framework for discussing network problems.
