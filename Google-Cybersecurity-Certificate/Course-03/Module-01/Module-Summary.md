# Module 1 Summary: Network Architecture and the TCP/IP Model

## 1. Network Structure

A network is made up of connected devices that communicate and share information. This module introduced two common network types:

- **Local Area Network (LAN):** Covers a relatively small area, such as a home, school, or office building.
- **Wide Area Network (WAN):** Spans a larger geographical area, such as a city, state, or country.

## 2. Common Networking Devices

The module introduced several standard devices used in networks:

- **Hub:** Broadcasts information to every device on the network.
- **Switch:** Connects specific devices and sends and receives data between them.
- **Router:** Connects multiple networks together.
- **Modem:** Connects a router to the internet and brings internet access to a LAN.

These devices have different roles in connecting devices and networks.

## 3. Cloud Networks

The module briefly introduced cloud networks and their benefits. Cloud computing involves using remote servers, applications, and network services hosted on the internet instead of relying only on local physical devices.

A cloud network is a collection of servers or computers that stores resources and data in remote data centers that can be accessed over the internet.

## 4. The TCP/IP Model

The TCP/IP model is a framework used to visualize how data is organized and transmitted across a network.

Technicians and security analysts use this framework to communicate where network problems have occurred. It gives them a shared way to discuss network communication and troubleshoot issues.

## Key Takeaways

- Networks can cover small or large geographical areas.
- Hubs, switches, routers, and modems perform different networking functions.
- Cloud networks use remote resources and data centers accessible through the internet.
- The TCP/IP model helps explain how data is organized and transmitted across networks.
- Technicians and security analysts use the TCP/IP model when communicating about network problems.
