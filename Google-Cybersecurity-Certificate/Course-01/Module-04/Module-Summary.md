# Module 4 Summary: Cybersecurity Tools and Programming Languages

## What I learned

This module introduced tools and technologies that support cybersecurity work.

One major topic was **security information and event management (SIEM)**. A SIEM application collects and analyzes log data from systems and other sources so an organization can monitor important activities and investigate possible security events. The course introduced **Splunk** and **Google Security Operations (Chronicle)** as examples of SIEM tools.

The module also introduced **playbooks**. A playbook is a documented set of steps that helps guide a team through a task or response process. Playbooks can make security work more consistent by helping people follow an organized procedure.

Another topic was the **network protocol analyzer**, also called a packet sniffer. This type of tool captures and analyzes network traffic. Security professionals can use network traffic analysis to better understand communication and investigate unusual activity.

The module introduced **Linux**, an open-source operating system that is widely used in technology environments. It also introduced databases and **SQL (Structured Query Language)**, which is used to create, interact with, and retrieve information from databases.

Finally, the module introduced programming and **Python** as useful foundations for giving computers instructions and automating tasks. It also covered digital evidence, including the importance of protecting and preserving evidence and understanding the order of volatility.

## Why this knowledge matters

Security professionals need ways to monitor systems, review events, investigate activity, and work with information. SIEM tools help organize log data, packet analyzers help inspect network traffic, and languages such as SQL and Python support working with data and automating tasks.

## Key takeaway

Cybersecurity work uses a combination of tools, operating systems, and programming languages. Understanding what these tools are designed to do is an important first step; practical ability develops through hands-on exercises and continued practice.

*This summary records introductory course learning. It does not claim hands-on proficiency with every named tool.*
