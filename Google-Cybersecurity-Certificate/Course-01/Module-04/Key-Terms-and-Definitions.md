# Module 4: Key Terms and Definitions

The following terms were introduced in **Cybersecurity Tools and Programming Languages**.

| Term | Meaning |
|---|---|
| **Antivirus software** | Software designed to help prevent, detect, and remove malware and viruses. |
| **Database** | An organized collection of information or data that can be stored, managed, and retrieved. |
| **Data point** | One specific piece of information in a dataset or record. |
| **Intrusion detection system (IDS)** | An application or system that monitors activity and alerts on possible intrusions or suspicious behaviour. |
| **Linux** | An open-source operating system. |
| **Log** | A record of events that occur in a system, application, or network. |
| **Network protocol analyzer (packet sniffer)** | A tool that captures and analyzes data traffic moving across a network. |
| **Order of volatility** | The order in which digital evidence should be collected or preserved, generally prioritizing data that is most likely to disappear or change. |
| **Programming** | Writing instructions that a computer can execute to perform tasks. |
| **Protecting and preserving evidence** | Handling digital evidence carefully so it is not accidentally changed, damaged, or lost. |
| **Security information and event management (SIEM)** | An application that collects and analyzes log data to help monitor important activities and investigate possible security events. |
| **SQL (Structured Query Language)** | A language used to create, query, and manage information in relational databases. |

## Quick examples

- **Log:** A record showing that a user signed in to an application at a particular time.
- **SIEM:** A security team uses a SIEM platform to bring together logs from servers, applications, and network devices.
- **IDS:** An IDS detects suspicious network activity and generates an alert for investigation.
- **Packet sniffer:** A network analyst captures traffic to inspect how devices are communicating.
- **SQL:** A query retrieves records from a database, such as user accounts created on a particular date.
- **Order of volatility:** During an investigation, evidence that may disappear quickly, such as data in active memory, is generally considered before data that is more persistent.

## Revision reminder

A **log** records events. A **SIEM** collects and analyzes log data from different sources. An **IDS** monitors activity and alerts on possible intrusions. A **network protocol analyzer** captures and examines network traffic. These tools have related but different purposes.
