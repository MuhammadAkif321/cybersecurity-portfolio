# Module 4: Cybersecurity Tools and Programming Languages

## Module overview

This module introduced common tools and technologies used in cybersecurity work. Topics included security information and event management (SIEM) tools, playbooks, network protocol analyzers, Linux, SQL, and Python.

## Learning topics

- SIEM tools, including Splunk and Google Security Operations (Chronicle)
- How SIEM tools collect and analyze log data
- Playbooks and repeatable response procedures
- Network protocol analyzers, also called packet sniffers
- Linux as an open-source operating system
- Databases and SQL
- Programming and Python
- Digital evidence and the order of volatility

## Main takeaway

Cybersecurity professionals use different tools and technologies to monitor activity, investigate possible incidents, analyze network traffic, work with data, and support security operations. Learning these tools takes practice and continued study.
