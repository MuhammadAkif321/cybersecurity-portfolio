# Module 2: The Evolution of Cybersecurity

## Module overview

This module explored how cybersecurity developed in response to influential attacks. It introduced early malware, more recent security incidents, social engineering techniques, threat actor motives, and the eight CISSP security domains.

## Learning topics

- Early malware examples, including the Brain virus and the Morris worm
- The LoveLetter attack and the Equifax data breach
- How older attack methods can influence or resemble modern attacks
- Social engineering and common phishing techniques
- Threat actor motives and attack methods
- The eight CISSP security domains as a way to organize areas of security work

## Main takeaway

Studying previous attacks helps security professionals understand how attacks can evolve and prepare to protect people and organizations against future threats.
