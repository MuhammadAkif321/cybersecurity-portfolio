# Module 3: Protects Against Threats, Risks, and Vulnerabilities

## Module overview

This module introduced security frameworks and controls and explained how organizations use them to establish security goals, create procedures, and manage risk. It also covered the CIA triad, the NIST Cybersecurity Framework, privacy, compliance, and security ethics.

## Learning topics

- Security frameworks and security controls
- Security goals, guidelines, processes, and procedures
- The confidentiality, integrity, and availability (CIA) triad
- The NIST Cybersecurity Framework (CSF)
- Compliance, privacy protection, and protected health information
- Security governance and security architecture
- Ethical responsibilities, including confidentiality and privacy

## Main takeaway

Security frameworks help organizations organize their security efforts, while controls provide safeguards for reducing specific risks. Ethical decisions and privacy protections are also essential parts of responsible cybersecurity.
