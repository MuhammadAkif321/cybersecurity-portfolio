# Module 3 Summary: Protects Against Threats, Risks, and Vulnerabilities

## What I learned

This module explained how organizations assess and manage cybersecurity risks by using **security frameworks** and **security controls**.

A security framework provides guidance for organizing security activities. It helps an organization identify its security goals and establish policies, guidelines, and processes to work toward those goals. Security controls are safeguards designed to reduce particular risks.

The module introduced the **confidentiality, integrity, and availability (CIA) triad**, a foundational model used when thinking about how to protect information and systems:

- **Confidentiality:** Only authorized people should be able to access information.
- **Integrity:** Information should remain accurate, authentic, and reliable.
- **Availability:** Authorized users should be able to access information and systems when needed.

The module also introduced the **NIST Cybersecurity Framework (CSF)** as a set of guidance, standards, and best practices that organizations can use to manage cybersecurity risk.

Another important topic was compliance. Organizations may need to follow internal policies and external laws or regulations. The module introduced examples involving health information, including HIPAA and protected health information (PHI).

Finally, the module discussed **security ethics**. Security professionals may work with confidential and personal information, so they must make responsible decisions, respect privacy, follow applicable laws, and protect sensitive data.

## Why this knowledge matters

Security is not only about installing tools. Organizations need clear goals, appropriate safeguards, responsible governance, and ethical practices. Frameworks help structure the work, while controls help reduce specific risks.

## Key takeaway

The CIA triad helps explain what security aims to protect. Frameworks such as the NIST CSF help organize risk-management activities, and security controls provide safeguards. Ethical behaviour and privacy protection must guide how security work is performed.
