# Module 2: Security Frameworks and Controls

This folder documents my learning from Module 2 of **Play It Safe: Manage Security Risks**, part of the Google Cybersecurity Professional Certificate.

## Module overview

In this module, I studied how organizations use security frameworks, security controls, and secure design principles to protect their data, systems, people, and other assets. I also learned how internal security audits help identify gaps between existing security practices and expected requirements.

## Topics covered

- Security frameworks and how they guide an organization's security program
- Security controls and their role in reducing risks
- The confidentiality, integrity, and availability (CIA) triad
- The NIST Cybersecurity Framework (CSF)
- NIST Special Publication 800-53
- OWASP and secure software design principles
- Security audits, including audit scope, goals, assets, and control assessments
