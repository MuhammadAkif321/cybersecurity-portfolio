# Module 1: Security Domains

This module introduces important areas of cybersecurity and the way organizations identify and manage security risks.

## Topics covered

- The focus of the eight CISSP security domains
- Threats, risks, and vulnerabilities
- Ransomware and its impact on organizations
- An introduction to the three layers of the web
- The seven steps of the NIST Risk Management Framework (RMF)

## Learning purpose

The purpose of this module was to build a foundation for understanding security domains and risk management. The concepts help explain how organizations recognize possible harm, understand weaknesses, and plan suitable security measures.
