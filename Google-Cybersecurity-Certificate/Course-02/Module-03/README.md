# Module 3: Security Tools — Logs and SIEM

This section documents my learning from Module 3 of **Play It Safe: Manage Security Risks**, part of the Google Cybersecurity Professional Certificate.

## Overview

This module introduced the role of system and network logs in cybersecurity monitoring. It covered common log sources, SIEM dashboards, and widely used SIEM platforms, including Splunk and Chronicle.

The module provides foundational knowledge of how security teams use event data to monitor an organization's environment, recognize unusual activity, and support incident investigations.

## Topics covered

- The purpose of logs in cybersecurity
- Firewall, network, and server logs
- SIEM concepts and dashboards
- Security monitoring and visibility
- Splunk Cloud and Splunk Enterprise
- Google Chronicle
- Metrics used to assess application performance
- Introductory concepts related to incident response, SOAR, and playbooks

## Professional relevance

Logs provide evidence of activity across an organization's systems. SIEM platforms bring data from different sources together so security teams can search events, identify patterns, investigate alerts, and support incident response.

Understanding these concepts is foundational for security monitoring and detection work.

## Scope and accuracy

This documentation records concepts introduced in the course. It does not claim professional experience or hands-on operation of Splunk, Splunk Cloud, Splunk Enterprise, or Chronicle. The scenario in this folder is an educational example, not a real incident or completed technical lab.
