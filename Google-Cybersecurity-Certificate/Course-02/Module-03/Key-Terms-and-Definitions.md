# Key Terms and Definitions — Module 3

The following definitions are written in clear, original wording for professional revision.

|---|---|
| **Chronicle** | A cloud-native security analytics tool designed to retain, search, and analyze security data. |

| **Splunk Cloud** | Splunk's cloud-hosted platform for collecting, searching, analyzing, and monitoring machine-generated data. |
| **Splunk Enterprise** | Splunk's platform that organizations can deploy and manage in their own environment to collect, search, analyze, and monitor machine data. |

## Important distinctions

### Logs vs. metrics
- **Logs** record individual events, such as a user signing in or a server reporting an error.
- **Metrics** measure values over time, such as average response time or service availability.

### SIEM vs. SOAR
- **SIEM** helps collect and analyze security events so analysts can detect and investigate suspicious activity.
- **SOAR** helps coordinate security tools and automate selected response workflows.

### SIEM vs. a playbook
- A **SIEM** analyzes event data and can generate alerts.
- A **playbook** documents the steps people or systems should follow when handling a particular event.

### Splunk Cloud vs. Splunk Enterprise
- **Splunk Cloud** is hosted as a cloud service.
- **Splunk Enterprise** can be deployed and managed by an organization in its own environment.
